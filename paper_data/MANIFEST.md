# Paper data

`specialist_20260914/` is the current data set: trot and walk specialists and
the trot push fine-tune, all trained under one protocol, with every evaluation
exported to CSV. Its `README.md` describes each file.

Earlier curated data (seed-2 paper policy, seed-3 adaptive selector, seed-4
high-duty walk, narrow-stance lineage and its push study) and the generated
figures are no longer in the tree. They are preserved at the git tag
`pre-specialist-data`:

    git checkout pre-specialist-data -- paper_data PAPER_GRAPHS
